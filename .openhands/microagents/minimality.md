# felt-overlay — minimality

Three similar lines beat a premature abstraction. Don't build a plugin
system, a config file format, or an animation framework for a program
that shows one static image and slides it in from one edge. Don't add
error handling or fallbacks for situations that structurally can't
happen given how this program is invoked. Don't add options/flags nobody
asked for "in case they're useful later." If the honest implementation
of Phase 1 is under a few hundred lines, that's a sign it's right-sized,
not a sign something's missing.
