# felt-overlay

A small, normally-invisible desktop overlay for [Felt](https://git.clockmost.com/Benylin/Felt) —
appears briefly on top of other windows when the assistant has something
to show, then recedes again. A "Shimeji-style" companion, distinct from
[felt-dashboard](https://git.clockmost.com/Benylin/felt-dashboard) (a
persistent embedded panel).

Design/scope: see `.openhands/microagents/repo.md` in this repo.

**Status: not yet built.** This repo currently only holds the task spec
for an autonomous OpenHands run — build instructions will land here once
Phase 1 (overlay mechanics + placeholder content) exists.
